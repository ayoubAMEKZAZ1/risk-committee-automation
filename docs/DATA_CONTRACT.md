# Input files and data-quality rules

All inputs are synthetic and generated by `src/committee/synth.py` from the shared synthetic portfolio.
Their layout is generic and invented for this repository; it does not reproduce any bank's files.

## Monthly inputs (`data/raw/<YYYY-MM>/`)

| File | Content | Notes |
|---|---|---|
| `exposures.csv` | One row per counterparty: ID, company, segment, sector, region, branch, RM, limit, on- and off-balance outstanding, days past due, internal rating (1-9, D), status | Semicolon-separated. The header spelling changes from month to month (accepted spellings in `config.yaml`). Amounts arrive as `1234.56` or `1 234,56`. |
| `candidates.csv` | One row per (counterparty, trigger) | The five triggers are: rating 8-9; 30-89 days past due; 2+ notch downgrade in 12 months; overdraft above its limit two months running; 3+ payment incidents in the month |
| `recovery.xlsx` | Names with the recovery team: transfer date, litigation stage, amount recovered | |
| `actions.xlsx` | Export of the action tracker: action, owner, due date, completion date | |

Two more files sit in `data/raw/`:
- `followup_tracker.xlsx`: the wide tracker, one column per committee date, rebuilt after each committee.
- `minutes/minutes_<date>.xlsx`: the committee's decisions, one row per name.

## Data-quality rules (`sql/checks/exposures.sql`, `pipeline.run_quality`)

| Rule | Severity | Check |
|---|---|---|
| DQ01 | Blocking | Conflicting duplicate rows for one counterparty |
| DQ02 | Info | Exact duplicate row, removed |
| DQ03 | Blocking | Missing mandatory field (ID, limit, on-balance, rating, status, RM) |
| DQ04 | Blocking | Negative amount |
| DQ05 | Warning | On-balance above 120% of the limit |
| DQ06 | Blocking | Rating outside the master scale |
| DQ07 | Blocking | Negative days past due |
| DQ08 | Warning | Status inconsistent with days past due (days past due prevails) |
| DQ09 | Info | ID trimmed or upper-cased |
| DQ10 | Warning | Watch-list name missing from the extract |
| DQ11 | Warning | Extract size more than 5% away from the median of the last 3 months (also fails control C2) |

## Injected defects (for testing only)

`synth.py` injects known defects into every extract, at rates of 0.1-0.5% of rows per type, and records
them in `data/raw/_truth/defects.csv`. In September 2025 one region is missing from the extract. The
pipeline never reads the truth file; `report.dq_detection` uses it to measure what the checks catch.
